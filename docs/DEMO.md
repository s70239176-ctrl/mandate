# Demo script (about 3 minutes)

The deployed app is already populated by `web/scripts/seed.mjs` from real consensus rounds, so this needs no setup. Use **Use demo account** (a throwaway Studionet key) for anything that signs.

1. **Home (15 s).** One sentence: *a treasury that can only act inside a written mandate, and reads the world before it moves.* Point at the four-step flow and click **60-second tour**; it walks stops 2 to 5 below on its own.
2. **Fund page (30 s).** The gold charter is the frozen mandate. The caps beside it are enforced by code. The treasury bar shows allocated, earmarked and idle GEN; position bars show how close each name is to its cap. The **standing watch** panel shows the frozen watch pages and the last scan.
3. **A proposal that went through (40 s).** Open *utility-scale solar*. Left card: the contract's own checks. Right card: the four answers the validators gave, with the real validator votes underneath. The stepper shows it passed the appeal window and the **last look**, then paid.
4. **A refusal and its reason (30 s).** Open *coal mining*. The mandate excludes fossil fuels, so the jury rejected it and the bond was slashed. The red "Because" line shows the machine-readable reason code.
5. **An appeal (30 s).** Open *onshore wind*. A member appealed with a different public page; a second jury read it and dismissed it. The appeal's bond stayed with the treasury.
6. **Live round (40 s).** Open the proposal left awaiting the jury (*geothermal*), click **Use demo account**, then **Ask the jury**. Watch the page say each validator is fetching the evidence itself; when it is accepted the checks fill in and the real votes appear.
7. **Watchdog fund (20 s).** Open *Watchdog Demo Fund*: its watch page documents an incident for a target the fund holds. See the scan result and whether the target is frozen (and the refused follow-up proposal).
8. **How it decides (15 s).** The exact instructions every validator receives, read from the contract, and the rules that are never given to a model.

Closing line: *the model answers a few narrow true/false questions about public pages; code does everything else; and anyone can read both.*
