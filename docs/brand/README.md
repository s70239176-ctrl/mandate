# Mandate brand

The mark is two nested triangles: a boundary, and what it contains. The amber core is the only colour.

| File | Use |
| --- | --- |
| `mark-on-dark.*`, `mark-on-light.*` | the mark alone, transparent background |
| `lockup-on-dark.*`, `lockup-on-light.*` | mark + MANDATE wordmark, transparent background |
| `lockup-dark-background.png`, `lockup-light-background.png` | the lockup on a solid background, ready to use |
| `app-icon.svg`, `app-icon-512.png` | rounded-square icon (also the favicon) |

Colours: ink `#050609`, off-white `#f4f4f7`, amber `#ffb879` (on dark) / `#e2872f` (on light). The SVG lockups set the wordmark in a system sans stack; the PNGs are the authoritative lettering. Regenerate everything with `node web/scripts/make-logo.mjs`.
