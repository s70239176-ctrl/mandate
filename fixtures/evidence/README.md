# Evidence fixtures

Two short public pages used by the demo path in `docs/SUBMISSION-FORM.md`, so a reviewer has stable, browser-readable evidence to cite (raw.githubusercontent.com allows cross-origin reads, so the app can fingerprint them in the page).

- `sunrow-solar.md`: a solar and storage operator. In theme for the renewable-energy mandate.
- `blackseam-coal.md`: a thermal-coal miner with a documented fatal safety incident. Excluded by that mandate.

The companies are invented for testing. Do not edit these files once a proposal cites them: a page that changes after it was fingerprinted is rejected.
